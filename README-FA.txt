سایت معرفی چت روم شیراز
=======================

فایل اصلی سایت: index.html
لینک گروه تلگرام: https://t.me/chatromshiraz

انتشار رایگان با GitHub Pages:
1) در GitHub یک حساب رایگان بسازید یا وارد شوید.
2) یک مخزن جدید (New repository) بسازید؛ نام پیشنهادی: chatromshiraz
3) برای انتشار عمومی، مخزن را Public قرار دهید.
4) فایل‌های index.html و robots.txt را در ریشه مخزن بارگذاری کنید.
5) به Settings > Pages بروید.
6) در Build and deployment، گزینه Deploy from a branch را انتخاب کنید.
7) Branch را روی main و پوشه را روی /(root) بگذارید و Save کنید.
8) پس از انتشار، آدرس سایت به شکل زیر خواهد بود:
   https://USERNAME.github.io/chatromshiraz/

مهم:
- در index.html مقدار YOUR-SITE-ADDRESS را با آدرس نهایی سایت عوض کنید
  (در تگ canonical). سپس فایل را دوباره بارگذاری کنید.
- آدرس دقیق GitHub Pages به نام کاربری شما وابسته است؛ آن را حدس نزنید.
- پس از انتشار، در Google Search Console مالکیت آدرس نهایی را تأیید کنید
  و URL Inspection > Request Indexing را بزنید.
- ایندکس و رتبه صفحه اول تضمین‌شدنی نیست و ممکن است زمان ببرد.
